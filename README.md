# 🛡️ BRACU Iron Dome

**BRACU Iron Dome** is a browser-based missile defense game created as a fun interactive project based on **BRAC University**.

The player takes the role of a missile-defense operator whose objective is to protect **BRAC University** from incoming missiles. The game becomes progressively more difficult as the player advances through different levels.

---

## 🌐 Play the Game

🎮 **Live Game:**
https://nimasnawfas.github.io/BRACU_Iron_Dome/

The game is hosted using **GitHub Pages** and can be played directly in a modern web browser.

---

## 🎮 Game Overview

In **BRACU Iron Dome**, missiles are launched toward BRAC University from the sky.

The player must:

* Detect incoming missiles
* Launch interceptors to destroy them
* Protect the university
* Manage limited ammunition
* React quickly to increasingly difficult attacks
* Achieve the highest possible score

The game features multiple levels, increasing missile activity, explosions, combos, and a final challenging stage.

---

## 🚀 Levels

### 🟢 Level 1 — WARM-UP

The first level introduces the player to the basic gameplay.

* Fewer incoming missiles
* Lower difficulty
* Gives the player time to understand the controls
* Focuses on learning how to intercept missiles

### 🟠 Level 2 — BARRAGE

The attack becomes more intense.

* More missiles appear
* Missiles arrive more frequently
* Players need faster reactions
* Chain combos become more important

### 🔴 Level 3 — FINAL STRIKE

The final level is the most difficult stage.

* Heavy missile attacks
* Faster gameplay
* Greater pressure on the player
* Special/mega missile warnings
* Requires effective use of interceptors and ammunition

---

## 🎯 Objective

The main objective is simple:

> **Defend BRAC University from incoming missiles for as long as possible.**

Destroy missiles before they reach the university.

The player must balance:

* Accuracy
* Reaction speed
* Ammunition
* Building health
* Interceptor timing

The longer the player survives and the more missiles they destroy, the higher the score.

---

## 🕹️ Controls

The game supports mouse and touch interaction.

### 🖱️ Mouse

* Move/click on the game area to target an incoming missile.
* Click to launch an interceptor.

### 📱 Touch

* Tap the screen to select a target and launch an interceptor.

### 🎛️ Game Controls

* **Pause/Play** — Pause or resume the game.
* **Restart** — Restart the current game.
* **Sound** — Turn game sound effects on or off.

---

## 💥 Gameplay Features

### 🚀 Missile Interception

Incoming missiles can be destroyed by launching interceptors toward them.

### 💣 Explosions

Successful interceptions create explosions and visual particle effects.

### 🔗 Chain Combos

Destroying multiple missiles successfully can create chain combos and increase the player's score.

### ⚠️ Mega Missile Warning

Some attacks include a warning for a powerful/mega missile, requiring the player to react quickly.

### 🏢 Building Health

The university has limited health.

If too many missiles reach the university, its health decreases.

The player must prevent the health from reaching zero.

### 🛡️ Dome Shield

The game includes a defensive dome/shield representing the missile-defense system protecting the university.

### 🔋 Ammunition and Reloading

Interceptors use ammunition.

The player needs to manage available ammunition and reload when necessary.

### 🔊 Sound

The game includes sound effects that can be enabled or disabled using the sound control.

---

## 🏆 Scoring

Players earn points by successfully intercepting incoming missiles.

Additional scoring can come from:

* Destroying multiple missiles in a chain
* Maintaining combos
* Successfully surviving difficult attacks
* Completing higher levels

The goal is to achieve the highest possible score.

---

## 🥇 Local Leaderboard

The game includes a local leaderboard using the browser's **localStorage**.

This allows players to save their scores locally on their device/browser.

The leaderboard does not require:

* A database
* A server
* User accounts

Scores are stored locally in the player's browser.

---

## 🔊 Sound System

The game includes sound effects to make the gameplay more interactive.

Players can toggle the sound on or off using the sound button.

## 💻 Technologies Used

The project is built using basic web technologies:

* **HTML5** — Game structure
* **CSS3** — User interface and visual styling
* **JavaScript** — Game logic, controls, animations, scoring, missiles, explosions, and gameplay
* **HTML Canvas** — Rendering the game
* **LocalStorage** — Local leaderboard/high-score storage

No backend server or database is required.

## ▶️ Running the Game Locally

You do not need to install Python, Flask, Node.js, MySQL, or any other backend software.

### Option 1 — Open Directly

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The game will open in your web browser.

### Option 2 — VS Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Run the file using a browser or Live Server.
4. Start playing.

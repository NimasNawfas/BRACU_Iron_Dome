## 📌 Overview

**BRACU Iron Dome** puts you in command of BRAC University’s tactical missile defense system. Your objective is simple yet challenging: intercept waves of incoming air strikes, manage critical interceptor ammunition, defend campus infrastructure, and survive increasingly relentless attacks.

> 🏆 **Designed for BUCC Club Fair**: Engineered entirely with native front-end web technologies requiring zero installation or backend setup—just open and play!

---

## ✨ Key Features

* **🎯 Precision Interception:** Real-time trajectory prediction and dynamic targeting using HTML5 Canvas graphics.
* **💥 Particle Explosions & Combos:** Chain multiple missile interceptions together to score massive multiplier bonuses.
* **⚠️ Mega Missile Threat Warnings:** High-priority visual alerts warning you of fast-moving, high-damage ordnance.
* **🛡️ Campus Health & Dome Shield:** Manage your localized air defense perimeter and keep building damage to a minimum.
* **🔋 Tactical Reload Mechanics:** Strategic ammunition management requires balancing firepower with firing delays.
* **🥇 Device-Local Leaderboard:** Automatically tracks and saves high scores locally using browser `localStorage`.

## 🛠️ Tech Stack

* **Structure:** HTML5
* **Styling:** CSS3 (Modern Flexbox/Grid UI)
* **Game Logic:** Pure Vanilla JavaScript (ES6+)
* **Rendering:** HTML5 Canvas API
* **Data Persistence:** Web Storage API (`localStorage`)
